7 Specialized AI Agents Working in Harmony

Unlike generic chatbot wrappers, every agent has a mathematically enforced boundary and Pydantic-validated output.

1. Data Profiling Agent

Audits schema, measures missingness and duplicate ratios, computes a 0-100% Data Quality Score, and infers business domain context.

2. Business Analyst Agent

Calculates verified revenue, net profits, margins, and AOV. Identifies top commercial growth drivers and explains correlations.

3. Trend Analysis Agent

Computes period growth rates, evaluates linear regression slopes, detects cyclical peaks, and issues strict forecasting disclaimers.

4. Anomaly Detection Agent

Combines IQR, Z-Score, and Isolation Forest algorithms. Explains outliers without baseless accusations of fraud.

5. Business Strategy Agent

Synthesizes all quantitative signals into prioritized executive action items with supporting evidence, business impact, and feasibility.

6. Report Generation Agent

Consolidates findings into an executive briefing and compiles publication-grade downloadable PDF reports using ReportLab.

Interactive Natural Language Querying

7. Business Query Agent (Zero-Eval Safety)

Ask questions like "What is the total revenue?" or "Which category has the highest margin?". The agent converts questions into Abstract Analytical Query Plans executed strictly with Pandas primitives — no arbitrary code execution risks.
